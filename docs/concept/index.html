Ein Endpoint. Alles integriert.

Synth vereint Datenzugriff und Messaging in einer API. AI Agents und Anwendungen nutzen dasselbe Protokoll für Files, Events und Scene-Komposition.

Kernfunktionen

Entwickelt für verteilte Content-Pipelines

📡

Unified API

Ein REST/gRPC Endpoint für Dateizugriff, Pub/Sub Messaging und Scene-Komposition. Keine separaten Systeme nötig.

🌍

Geo-Routing

Automatische Auswahl des optimalen Nodes basierend auf Standort und Latenz. Verteilte Infrastruktur ohne Komplexität.

🤖

AI-Native

MCP-Integration ermöglicht AI Agents direkten Zugriff auf Content-Operationen. API-first statt GUI-first Design.

🧩

Scene Composition

Szenen aus verteilten Ressourcen automatisch zusammenstellen. Paralleles Laden mit Dependency-Management.

💾

Intelligentes Caching

Mehrere Cache-Strategien von "Network-First" bis "Stale-While-Revalidate". ETags und Range-Requests inklusive.

📨

Event Messaging

Pub/Sub mit Consumer Groups, Message Replay und verschiedenen Delivery-Garantien. Alles über denselben Endpoint.

Das Protokoll

Einfache, konsistente API

// Ressource laden
GET /api/v1/resources/scenes/forest.glb
Authorization: Bearer {token}

// Event publizieren
POST /api/v1/messages/publish
{
  "topic": "scenes/forest/updated",
  "payload": { "action": "modified" }
}

// Scene komponieren
POST /api/v1/scenes/compose
{
  "scene_uri": "synth://hub/scenes/forest",
  "options": {
    "max_concurrent": 8,
    "use_cache": true
  }
}

// Events empfangen (Long-Poll)
GET /api/v1/messages/poll?topic=scenes/*&timeout=30
