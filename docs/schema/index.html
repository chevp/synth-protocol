Synth Protocol - XML Schemas

This page provides access to XML Schema Definitions (XSD) for the Synth Protocol.

Available Schemas

Component Schema

  • component.xsd (v1.0)
    Namespace: https://chevp.github.io/synth-protocol/schema/synth/component/1.0

    Schema for Synth component definitions. Used in .synth.xml component files.

Scene Schema

  • scene.xsd (v1.0)
    Namespace: https://chevp.github.io/synth-protocol/schema/synth/scene/1.0

    Schema for Synth scene definitions. Used in scene .synth.xml files.

Project Schema

  • project.xsd (v1.0)
    Namespace: https://chevp.github.io/synth-protocol/schema/synth/project/1.0

    Schema for Synth project configuration files.

Usage Example

Component Definition

<?xml version="1.0" encoding="UTF-8"?>
<synthComponent version="1.0" id="my-component"
                xmlns="https://chevp.github.io/synth-protocol/schema/synth/component/1.0"
                xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
                xsi:schemaLocation="https://chevp.github.io/synth-protocol/schema/synth/component/1.0
                                    https://chevp.github.io/synth-protocol/schema/synth/component/1.0/component.xsd">
    <metadata>
        <name>My Component</name>
        <type>custom</type>
    </metadata>
    <properties>
        <property name="enabled" type="bool" value="true"/>
    </properties>
</synthComponent>

Scene Definition

<?xml version="1.0" encoding="UTF-8"?>
<synthScene version="1.0" id="my-scene"
             xmlns="https://chevp.github.io/synth-protocol/schema/synth/scene/1.0"
             xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
             xsi:schemaLocation="https://chevp.github.io/synth-protocol/schema/synth/scene/1.0
                                 https://chevp.github.io/synth-protocol/schema/synth/scene/1.0/scene.xsd">
    <metadata>
        <name>My Scene</name>
    </metadata>
    <entities>
        <entity id="player" name="Player">
            <transform>
                <position x="0" y="0" z="0"/>
            </transform>
        </entity>
    </entities>
</synthScene>

Local Development

For local development, you can use an XML catalog to resolve schema URLs to local files. See the docs/schema/catalog.xml file.
