5-Slot Grammar


            

                
Statement Format

                domain [resource] action subject [modifier target] [--args]
            


            

                
Examples

                project create my_game
                scene create outdoor in my_game
                cluster node create player in outdoor
                component create transform on player
                component update transform on player --position=0,0,0
                mcp server start vision
                mcp tool invoke analyze on vision
                agent task complete scan by analyzer
            


            
Slot 1: Domain

            

                scene Scene management

                cluster Node hierarchy

                component Components

                mcp MCP servers

                agent AI agents

                project Project level

                asset Assets

                plugin Plugins

                system System
            


            
Slot 2: Resource

            

                node Scene node

                server MCP server

                tool MCP tool

                task Agent task

                selection Selection

                folder Folder

                file File

                setting Setting

                session Session
            


            
Slot 3: Action

            

                create update delete

                start stop

                enable disable

                move rename select

                connect disconnect

                invoke complete fail

                register unregister

                open save close
            


            
Slot 5: Modifier

            

                in container

                on surface/target

                to destination

                from source

                by actor

                for purpose

                with accompanying

                at location
