Synth DSL Grammar


            

                
Document Structure

                synth "name" [version] {
                  meta { ... }
                  scene "id" { ... }
                  mcp { ... }
                  agents { ... }
                  events { ... }
                }
            


            
Blocks

            

                synth Root document

                meta Project metadata

                scene Scene definition

                node Scene graph node

                folder Node container

                component Node component

                mcp MCP servers

                server MCP server

                agents AI agents

                agent Agent definition

                events Event history

                assets Asset references
            


            
Components

            

                transform Position/rotation/scale

                material Material reference

                mesh Mesh reference

                script Script attachment

                collider Physics collider

                light Light source
            


            
Event Syntax (Subset)

            

                event domain [resource] action subject [modifier target] [args]
            


            
Property Types

            

                "string" Text value

                123 Number

                true/false Boolean

                (x, y, z) Vector3

                @ref Reference
