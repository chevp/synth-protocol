# =============================================================================
# URI STRUCTURE
# =============================================================================
#
#   scheme://path/action#subject?query
#
#   scheme   = synth | nuna | mcp | plugin
#   path     = resource path (e.g. cluster/node, mcp/server, agent/task)
#   action   = create | update | delete | start | stop | invoke | complete | fail | ...
#   subject  = instance ID (fragment)
#   query    = key=value pairs (URL encoded)
#
# =============================================================================
